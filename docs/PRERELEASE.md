# Beta status / 测试版状态

No game file or ready-made app is supplied. Results come from one Apple M1 (16 GB).

## Demonstrated

- Campaign, Zombies and multiplayer against bots on the Steam executables, through their menus.
- Multiplayer and Zombies without the daily patch file, using this project's own rules script.

## Not yet demonstrated

| Area | Remaining evidence |
| --- | --- |
| Other machines | Another Mac, a fresh macOS account, 8 GB of memory |
| Campaign | Every mission played end to end; save, quit and resume |
| Multiplayer and Zombies | Long sessions played by hand; Sharpshooter through the real menu |
| Network | Online play, LAN and co-op are not supported |

不提供任何游戏文件，也不提供现成的应用。结果来自一台 Apple M1（16 GB）。已证实：三种模式都能在 Steam 可执行文件上
通过各自的菜单运行；多人模式和僵尸模式在没有每日补丁文件的情况下，使用本项目自己的规则脚本运行。尚未证实：其他 Mac、
全新的 macOS 账户、8 GB 内存；每个战役任务完整通关，以及存档、退出和继续；多人模式和僵尸模式的长时间手动游玩。
不支持在线游戏、局域网和合作模式。
