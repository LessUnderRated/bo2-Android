# Wave 5 — the audio DSP's COMPUTED-JMP filter tables (0x926a00-0x927580).
#
# Four unrolled multiply-accumulate chains (two fixed-point, two x87) that a
# `jmp edx` enters at a computed offset chosen by the filter length. The entry
# offsets are NOT branch targets in the byte stream, so a linear branch-leader
# sweep cannot see them -- wave 4 harvested this region and still missed every
# one of them. The run died on `__remill_jump: unknown target 0x927547`, which
# is entry n=29 of chain B.
#
# Each set is derived from the guest's own address arithmetic rather than from
# a sweep, so it is complete by construction:
#   A  jmp edx @0x9270a2          edx = 0x9271c4 - 9*n,   n = 1..32
#   B  jmp edx @0x927440/0x927574 edx = 0x927562 - 9*n,   n = 1..32
#   C  jmp edx @0x926a45/0x926bc2 edx = 0x926bbb - 11*n,  n = 1..33  (-9 at n=33:
#                                   the first tap needs a disp32, so it is 9
#                                   bytes longer than the other 32)
#   D  jmp edx @0x926bea/0x926d56 edx = 0x926d4c - 11*n,  n = 1..32
